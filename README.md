# GitHub Hide Latest Commit Elements

uBlock Origin Filter for GitHub That:

- Hides the Latest Commit Elements (Summary Box, Message and Age) for an Easier Glance.

## Installation

Add the Contents of [`ublock-origin-static-filter.txt`](ublock-origin-static-filter.txt) to uBlock Origin Under **Dashboard → My Filters**.
